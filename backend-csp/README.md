# API-SCHOOL Backend SaaS

## Installation
1. `npm install`
2. Copier `.env` et configurer PostgreSQL (Neon recommande)
3. `npx prisma migrate dev --name init`
4. `npm run prisma:seed`
5. `npm run dev`

## API Docs
`http://localhost:5000/api-docs`
